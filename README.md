# Cybersecurity
 
Cybersecurity concepts, explained through worked examples. Each file takes a
framework or deliverable type and works through it in full, rather than just
summarizing the theory — the goal is to show how these concepts get applied, not
just define them.
 
## Contents
 
- **[McCumber Cube](./mccumber-cube.md)** — a full 27-cell worked example of the
  CNSS/McCumber Cube model, mapping specific policy, education, and technology
  safeguards across all combinations of security property (confidentiality,
  integrity, availability) and information state (storage, processing,
  transmission).
- **[Risk Register](./risk-register.md)** — a complete GRC risk register for a
  fictional mid-sized medical practice, built as part of ISMS coursework. Covers
  10 risks scored with a documented likelihood × impact methodology, existing
  controls, residual risk, and tiered low-effort/high-effort treatment plans with
  target risk scoring.
- **[HIPAA → NIST CSF 2.0 Crosswalk](./HIPAA-NIST-CSF-2.0-Crosswalk.md)** — maps all 18
  HIPAA Security Rule standards to their corresponding NIST Cybersecurity
  Framework 2.0 category, modeled on the mapping approach used in NIST SP 800-66
  Rev 2. Presented as a single scannable table with one primary category per
  standard, plus notes on where the reasoning shifted during development.

## Why this repo exists
 
Built while studying for a GRC-track cybersecurity internship and coursework —
a place to work through frameworks in enough depth to actually defend the
reasoning behind them, not just cite the name.
